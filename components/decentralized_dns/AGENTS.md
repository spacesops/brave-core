# Decentralized DNS

## Spaces Protocol implementation log

`SPACES-PROTOCOL.md` is the running log for Spaces Protocol (`.spaces`)
hostname resolution. Name-format details are in `spaces-names.md`.

- Read `SPACES-PROTOCOL.md` before working on Spaces Protocol.
- Update it after each meaningful step:
  - **Status**: change the phase's state and record the commit hash.
  - **Remaining work**: tick off finished items and add new ones.
  - **Open questions**: record decisions and the reason for them, and remove
    answered questions.
  - **Build and test notes**: add new gotchas, commands, or timings.
  - **How decentralized DNS works**: correct anything that turned out wrong.
- Record only things verified in code or by a build or test. Edit sections in
  place rather than appending a chronological diary.
